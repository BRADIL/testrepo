# Promora MVP

This is a minimal Expo project implementing Promora, a social commerce platform prototype.

## Requirements
- Node.js >= 18
- Expo CLI (`npm install -g expo-cli`)

## Setup
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm start
   ```
3. For web:
   ```bash
   npm run web
   ```

This project includes placeholder screens for Influencer, Brand, and Admin roles. Navigation is handled with React Navigation. Styling uses a simple theme defined in `theme.ts`.
